# 获取项目信息流程

本文档描述获取项目工程信息的完整流程，包括检查远程软件工程列表。输出判断结果，根据结果判断后续操作。

## 流程概览

```
获取远程项目信息 → 检查软件工程列表 → 判断结果
```

## 前置条件

- 用户已登录（`token`、`user_id` 存在）
- `api_base_url` 已配置
- `project_id` 已设置

## 工具清单

| 步骤 | 工具名称 | 来源文件 | 状态 |
|------|----------|----------|------|
| 1 | `get_local_project_info` | `project_manager_tools.py` | 已注册 |
| 2 | `get_project_info` | `project_manager_tools.py` | 已注册 |
---

## 详细步骤

### 步骤 1: 获取远程项目信息

**目的**: 获取项目详情及关联的软件工程列表。

**使用工具**: `get_project_info`

### 步骤 2: 检查本地工作空间状态

**目的**: 检查本地是否已有软件工程。

**使用工具**: `get_local_project_info`


### 步骤 4: 判断结果
请输出以下判断结果中的任何一个
1.无软件工程
  条件：获取远程项目信息中 softwares 没有数据
2.有软件工程,无本地工程 
 条件： 获取远程项目信息中 softwares 有数据且本地工作空间状态中 software_projects 没有数据
3.有软件工程,有本地工程
  条件：获取远程项目信息中 softwares 有数据且本地工作空间状态中 software_projects 有数据
